# RevizUp

RevizUp est un projet de fin d'année en Licence 2. C'est une application web destinée à aider les étudiants à organiser leurs révisions, suivre leur progression et gérer leurs matières.

## Fonctionnalités prévues

- Page d'accueil avec présentation du projet
- Gestion de l'authentification : connexion et inscription
- Tableau de bord utilisateur pour suivre les révisions
- Gestion des matières / cartes de révision
- Style personnalisé avec `forme.css`

## Structure du projet

- `index.php` : page d'accueil du site
- `login.php` : page de connexion
- `signup.php` : page d'inscription
- `config.php` : fichier de configuration (base de données, paramètres)
- `dashborbd.php` : tableau de bord (dashboard)
- `cartes.php` : gestion des cartes de révision
- `forme.css` : styles CSS du site
- `images/` : dossier pour les images et ressources multimédias

## Installation

1. Installer XAMPP ou un serveur local compatible PHP.
2. Copier le dossier `RevizUp` dans le répertoire `htdocs` de XAMPP.
3. Démarrer Apache (et MySQL si nécessaire).
4. Ouvrir un navigateur et visiter `http://localhost/RevizUp/`.

## Développement

- Compléter les pages `login.php`, `signup.php`, `config.php`, `dashborbd.php` et `cartes.php` selon la logique attendue.
- Ajouter la connexion à une base de données MySQL dans `config.php`.
- Créer les tables nécessaires pour les utilisateurs, les matières et les cartes de révision.
- Ajuster le CSS dans `forme.css` pour améliorer l'interface.
